# OMNIX

OMNIX is an experimental AI language model built from scratch.

## Version

OMNIX 1.0.0

## Web AI

OMNIX includes a web interface with:

- FastAPI backend
- HTML frontend
- CSS interface
- JavaScript chat client
- NumPy-based AI engine
