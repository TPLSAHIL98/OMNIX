# OMNIX

OMNIX is an experimental open-source language model built from scratch.

## Version

Current version: **1.0.0**

## Goals

OMNIX is being developed progressively:

- 1.0 — Transformer foundation
- 1.1 — Improved tokenizer and training
- 1.2 — Better dataset pipeline
- 1.3 — Instruction tuning
- 1.4 — Coding capabilities
- 1.5 — Minecraft specialization
- 2.0 — Major architecture upgrade

## Architecture

OMNIX 1.0 uses a small decoder-only Transformer with:

- Causal self-attention
- Token embeddings
- Positional embeddings
- MLP blocks
- Layer normalization
- Weight tying
- Autoregressive generation
